# sink.fi

Static site and app mock. No framework, no build step.

- index.html: home
- docs.html: docs
- app/: deposit (index), portfolio, vote, stats
- spec.html: type, colour, grid, waterline and logo spec
- logo/: mark, wordmark and lockups as SVG, ink on paper and paper on ink, plus favicon
- js/countdown.js: the only script. Edit the dates at the top of the file (epoch 1 start and the points choice deadline).

GitHub Pages: push this folder to a repo and enable Pages on the main branch root. For app.sink.fi as its own subdomain, serve the app/ folder from a second repo or a redirect.

Before launch: set the X link (currently https://x.com/) in every footer and header.
